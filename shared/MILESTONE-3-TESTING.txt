DASHBOARD 4.0 — MILESTONE 3.1 TESTING
Participation → Google Classroom Grade Sync + Topics + Due Date

GOOGLE CLOUD CHANGE
Add this OAuth scope in Google Auth Platform → Data Access:
https://www.googleapis.com/auth/classroom.topics

Then reconnect Google Classroom in Dashboard Settings so Google grants the new permission.

SAFE TEST
1. Leave “Publish assignments immediately” UNCHECKED.
2. Connect Google Classroom.
3. Choose the participation term and assignment point value.
4. Choose an existing Topic, choose “Create New Topic…”, or leave Topic blank.
5. Optional: set a Due Date. Due Time defaults to 11:59 PM.
6. Click Save Grade Settings.
7. Click Create / Update Assignments. Existing Dashboard-created draft assignments are updated in place.
8. Verify the draft in Classroom has the expected title, points, topic, and due date/time.
9. Preview Grades.
10. Push Draft Grades only after the preview looks correct.

TOPIC BEHAVIOR
The Dashboard stores the topic by NAME because Google Classroom topic IDs are different in every course.
For each mapped Classroom, the Dashboard uses the existing topic with that name. If it does not exist, the Dashboard creates it in that Classroom.

DUE DATE BEHAVIOR
Leave Due Date blank for no due date. If a date is set, the Dashboard sends both the date and time because the Classroom API requires them together. Browser-local date/time is converted to the UTC fields expected by the Classroom API.

GRADE MATH
Classroom grade = (participation points / participation goal) × assignment points
Scores are capped at the Classroom assignment maximum. Whole-number rounding remains optional.
