Advanced Google Setup
The OAuth access token is kept only for the current page session. Your course mappings and imported roster data remain in the Dashboard's existing browser storage; Google Drive sync is not used.
Google Cloud setup
  1. Enable the Google Classroom API in your Google Cloud project.
  2. Create or use an OAuth 2.0 Web application client.
  3. Add the site where this Dashboard is hosted to the client's Authorized JavaScript origins.
  4. Paste that Web Client ID above. This build requests course/roster access plus classroom.coursework.students so it can create Participation assignments and write draft grades.

New School Year Reset

Prepare the dashboard for a new group of students without rebuilding your school bell schedules.

The following will be reset
  • Master rosters and Google Classroom course mappings
  • Hidden periods (all seven become visible)
  • Custom period/class names
  • Minimum-day dates
  • Participation records and Participation Tracker undo history
  • Student Picker pools, history, and generated groups
  • Scoreboard championships, scores, competitions, and history
  • Agenda history and saved agenda entries
The following will not be changed when performing a New School Year Reset
  • Regular bell schedule
  • Wednesday Late Start schedule
  • Minimum Day bell times
  • Bell alarm sound, Final Bell setting, and custom-warning default
  • Student Picker style/target choices and group-size preferences

Before anything is erased, the dashboard automatically creates one complete pre-reset backup containing shared Dashboard data plus Scoreboard, Student Picker, Participation Tracker, Agenda, and bell-session state. Undo Last School Year Reset restores that most recent backup.
